# 智能体设计实例：数据库安全运维教学智能体

## 基本信息

- **项目序号：**01/04
- **智能体名称：**基于大语言模型的数据库安全运维教学智能体
- **项目副标题：**面向 MySQL 数据库巡检、权限管控、备份恢复与安全事件处置的情景化学习助手
- **支撑课程：**数据库原理与安全
- **项目类型：**基于智能体的网络安全小助手开发—网安专业课情景教学

## 对应课程内容

“数据库原理与安全”，覆盖以下内容：

1. MySQL 安全基线巡检；
2. 数据库账号与权限审计；
3. SQL 注入风险及异常日志分析；
4. 数据库备份、恢复验证与应急闭环。

## 核心教学任务

1. 掌握 MySQL 安全基线巡检的常用命令与检查方法；
2. 识别异常账号、越权授权和高风险访问来源；
3. 分析审计日志与可疑 SQL，研判 SQL 注入及数据泄露风险；
4. 完成备份有效性检查、恢复演练和安全运维报告编写。

## 配套故事线设计（企事业单位真实场景，多分支决策）

### 故事背景

某市公共服务平台的 MySQL 业务数据库出现异常高权限账号和大量可疑查询，同时夜间备份任务执行失败。平台存储用户身份信息和业务办理记录，存在数据泄露及服务中断风险。单位要求数据库安全运维岗（学员扮演）在 2 小时内完成风险排查、权限处置、备份恢复验证和安全加固。

### 可扮演角色

- 数据库安全运维工程师；
- 数据库管理员；
- 应急响应工程师。

### 核心决策点与故事线分支

1. **决策 1：先做安全基线巡检**  
   进入“MySQL 安全基线检查”任务，发现远程高权限登录、弱密码策略和审计配置不足；完成后解锁“账号权限审计”。

2. **决策 2：先做账号权限审计**  
   进入“账号与权限分析”任务，发现新增可疑账号和业务账号权限过大；完成后解锁“日志与可疑 SQL 分析”。

3. **决策 3：先分析异常日志**  
   进入“SQL 日志分析”任务，识别批量查询、异常登录来源及疑似 SQL 注入行为；完成后解锁“备份恢复验证”。

三个分支最终汇合到“风险处置与闭环”任务：撤销不合理权限、禁用异常账号、验证安全备份、在隔离数据库中完成恢复，并生成处置报告。

### 失败分支

若任务超时、误判风险或执行危险 SQL，故事线推进为“数据库再次遭受异常访问，敏感数据存在泄露风险，备份恢复失败”。学员需要根据智能体提示重新完成任务。

## 模拟攻击方案（仅限教学沙箱）

本项目采用“受控攻击回放”方式构造教学事件。攻击过程由固定场景和预设事件驱动，只作用于隔离的 MySQL 教学沙箱和合成数据，不提供外部攻击入口，不允许学员或大语言模型执行任意攻击载荷。

### 模拟攻击链

1. **入口阶段—SQL 注入迹象：**回放预设的异常 Web 请求和数据库日志，模拟业务系统参数化查询缺失后产生的 SQL 注入迹象。
2. **权限利用阶段：**模拟应用账号权限配置过大，使其能够访问超出业务职责范围的数据表，并生成异常授权证据。
3. **异常访问阶段：**对合成用户数据执行受限的批量查询回放，产生非工作时段访问、查询量突增和敏感表读取记录。
4. **持久化阶段：**在场景初始化时预置来源异常的高权限账号，供学员完成识别、研判、锁定和权限回收。
5. **备份干扰阶段：**模拟备份任务失败、校验值不一致或最新备份不可用，不实际删除备份文件和业务数据。
6. **证据生成阶段：**形成 Web 访问日志、MySQL 日志、账号权限快照、备份记录和场景事件时间线，供学员分析与处置。

### 学员处置任务

- 定位异常请求和可疑 SQL；
- 识别被滥用的应用账号和异常高权限账号；
- 撤销过度授权并锁定可疑账号；
- 验证备份文件，在隔离恢复库中完成恢复验证；
- 完成安全加固、证据整理和事件报告。

### 安全控制

- 仅使用合成或脱敏数据；
- 沙箱禁止访问外网和宿主机其他数据库；
- 攻击事件只能通过固定场景编号触发，不接受任意攻击参数；
- 大语言模型不能直接执行 SQL，只能调用后端受控工具；
- 限制查询数量、执行时间和资源占用；
- 拦截删除库表、无条件批量修改等破坏性操作；
- 每次演练结束后可一键恢复标准快照。

## 智能体核心功能

1. **故事线引导与多分支任务：**通过角色对话、事件提示和决策节点推动任务进程。
2. **受控攻击回放模块：**按固定场景注入异常状态、日志和证据，支持开始、暂停、重置和结果校验。
3. **MySQL 教学沙箱与操作校验：**在隔离环境中执行只读查询和白名单操作，实时校验操作结果。
4. **安全基线自动巡检：**检查账号、口令策略、远程访问、日志、权限及备份配置等项目。
5. **账号权限审计与风险评分：**识别异常账号、过度授权和高风险来源，并给出风险等级。
6. **SQL 日志分析与注入风险讲解：**从模拟日志中识别异常查询，解释风险原理与处置思路。
7. **备份恢复模拟：**检查备份完整性，在隔离数据库中进行恢复验证。
8. **知识问答与错误操作提示：**结合课程知识库解释任务要求，针对错误操作给出分级提示。
9. **学习评分与报告生成：**记录任务路径、用时、错误次数和风险处置结果，生成数据库安全运维报告。
10. **危险 SQL 拦截：**大语言模型只能提出操作建议，实际数据库操作必须经过固定接口、权限校验和白名单控制。

## 教学闭环

场景初始化 → 受控攻击回放 → 故事线引导 → 学员决策 → 沙箱实操 → 操作校验 → 知识讲解 → 风险处置 → 评分反馈 → 报告生成 → 场景重置。
