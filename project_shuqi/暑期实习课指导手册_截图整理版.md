## 一、实习目的

随着人工智能技术高速迭代升级，AI 应用落地、智能体开发已成为职场核心刚需能力。目前各大企事业单位在人才招聘中，均将 **AI 应用实操、智能体开发能力**作为核心考核标准，兼具网络安全实操能力与 AI 智能体开发技能的复合型人才，已成为行业紧缺人才。

为适配新时代行业人才需求，助力 2026 暑假实习课学员突破技能壁垒、提升职场核心竞争力，本暑期实习课具体安排与培养优势如下：

### 1 核心培养定位：双技能融合，打造复合型人才

本次实习打破单一技能训练局限，依托成熟的网络安全基础训练体系，新增全员智能体开发专项实习模块，保障每一位参训学员都能沉浸式参与智能体全流程实操训练。

通过“网络安全岗位知识 + AI 智能体开发”双核心课程体系，补齐学员 AI 技术短板，让学员同时掌握两大核心职业技能，精准匹配企业招聘刚需，实现从基础技术学习者到实战型技术人才的蜕变。

### 2 创新教学模式：多维保障，提升实习实效

实习班摒弃传统单向授课模式，搭建“自主学习 + 名师引导 + 实时答疑 + 专项辅导”的立体化教学体系，全方位保障学员学习效率与实操效果：

- **系统化自主学习资源：**配套完善的钉盘实习课件、实操教学视频，覆盖典型网安岗位；学员可根据自身学习节奏自主复盘、反复研习，夯实理论与实操基础。
- **企业级师资全程赋能：**由专业企业教练全程带队，负责实习导航、实习节奏把控，精准引导学员高效完成实习任务；企业资深工程师入驻微信、钉钉专属社群，快速响应学员疑问，指导实习过程中的各类项目任务、技术问题。
- **专属技术答疑渠道：**依托官方实习系统（www.anquan1000.com）专属答疑板块，针对各类技术问题开展线上互动答疑，问题留存可追溯、知识点可复盘，高效攻克技术难点。
- **智能体开发专项辅导：**针对核心的智能体开发模块，配备专属助教团队，跟进学员开发过程，针对代码编写、功能设计、架构优化等环节提供专业完善的优化建议，助力学员打造高质量开发成果。

### 3 标准化实习考核：以成果落地，验证能力提升

为确保实习成果可视化、能力提升可量化，实习课制定标准化、体系化的实习任务与结班考核机制。实习期间发布实习项目，拆解各模块智能体开发专项任务，循序渐进推进实习教学。

为全方位、多维度检验学员实习成效，结合智能体开发成果提交，形成“理论 + 实操 + 项目成果”三位一体的综合考核体系。所有考核成绩将正式纳入实习结课证明，作为学员实习能力认证的核心依据。

实习结束前，所有学员需独立完成并提交完整的智能体开发实战成果，由专业助教团队统一验收审核，全方位检验学员的设计、开发、风控、复盘综合能力，四项成果完整闭环智能体开发全流程：

- **智能体规划设计方案：**验证学员需求分析、架构规划、整体设计的前期统筹能力；
- **智能体功能手册：**考核学员功能梳理、逻辑梳理、技术文档撰写的专业能力；
- **智能体源代码及数据库压缩包：**落地核心开发能力，检验学员代码编写、数据库搭建、功能落地的实操功底；
- **智能体源代码安全审计报告：**结合网络安全核心优势，培养学员代码风控、漏洞排查、安全优化的高阶能力，实现安全技术与 AI 开发的深度融合。

整套实习体系从理论学习、实操训练、专项辅导到成果落地、严格考核，层层递进、闭环赋能，切实帮助学员扎实掌握 AI 智能体开发核心技能，夯实网络安全实操基础，积累高质量实战项目成果，全面提升求职核心竞争力。

### 4 自愿申报认证考试

> 注：实习活动学员如果有意向参加认证证书考试，自愿联系授课教师报名认证考试；认证考试配套考前强化辅导、安全实操云端环境和模拟题库，具体考试安排及证书权益如下。

#### （1）结业统一考试安排

- **理论知识考核：**考试时间为 7 月 24 日，重点考核网络安全相关基础理论、技术原理等核心知识点，夯实学员专业理论功底。
- **实操能力考核：**考试时间为 7 月 24 日，聚焦实战应用能力，考核学员攻防技术核心实操技能，检验真实落地技术水平。

#### （2）考核通关权益与证书优势

学员理论、实操双科考试成绩合格后，即可获得“国家信息安全保障人员 CISAW 认证（预备级）”申报资格。有意向取证的学员，可联系授课教师统一向中国网络安全审查认证和市场监管大数据中心提交证书申请。该证书具备高含金量与长期使用价值，学员毕业后可直接将大学生版证书转换为企业版证书，无需重复培训、无需再次考试，大幅降低后续职业考证成本，有效提升个人就业竞争、职场升职的核心竞争力。

### 2 基于智能体的网络安全小助手开发—企业网安知识情景教学

#### Agent09：Linux 攻防演练与应急实践课

本课程围绕 Linux 系统应急响应与安全溯源，涵盖系统与网络信息排查、异常进程及可疑文件检测、Rootkit 查杀、常见后门识别（如软链接、计划任务、自启动项）、日志分析、恶意 IP 关联研判、黑客内网扫描行为发现等内容，并介绍系统安全加固措施，如账户策略、访问控制、资源限制及关键软件的版本升级与安全配置。

#### Agent10：Windows 攻防演练与应急实践课

本系列课程涵盖 Windows 环境下典型恶意程序的模拟、识别与处置，包括钓鱼载荷投递、各类 Webshell（一句话木马、小马、大马、内存马）部署与清除、后门及挖矿病毒行为分析，并系统讲解恶意进程、服务、计划任务、异常账户的排查方法，以及基于账户策略、防火墙、启动项和权限控制的系统安全加固措施。

#### Agent11：数据库攻防演练与应急实践课

聚焦数据库攻防演练与应急响应，涵盖 SQL 注入漏洞利用、Web 应用安全加固及数据库安全配置，提升学员攻防实战与应急处置能力。

#### Agent12：网络设备安全配置与应急实践课

围绕网络架构安全分析与应急实践，涵盖防火墙策略、NAT 规则、WAF 部署、堡垒机权限管控、多类型 VPN 配置等关键环节，通过模拟攻击与防护配置，提升网络边界防御与应急响应能力。

#### Agent13：软件安全开发与 SDL 管控实践课

本课程专注于 SecDevOps 流程化教学，通过模拟企业真实场景，强化软件开发人员、IT 安全团队和运营人员间的合作与沟通。课程内容涵盖代码漏洞自动化发现、修复与验证的全流程实践，包括 CORS、CSRF、fastjson、SQL 注入、SSRF、XSS、命令注入及验证码漏洞等防御实战。学员将学习漏洞产生背景、原理、修复方法，并进行代码修复实践与漏洞验证，确保安全性贯穿于软件开发生命周期（SDLC）各环节，旨在提升团队协同效率，增强软件安全性和防御能力。

#### Agent14：供应链安全管控与代码安全审计课

本课程专注于供应链安全管控与代码安全审计，涵盖供应链安全检测流程制定、开源代码安全隐患分析及检测技术实践。通过实操演练，深入讲解加解密技术，以及单向和双向认证机制在供应链防护中的应用。课程内容包括常见网络攻击类型与防御措施、开源代码检测关键项与报告分析、加密技术原理及其在保障供应链安全中的作用，旨在提升学员对供应链和代码安全的全面理解和实战能力。

#### Agent15：WEB 安全攻防与 SDL 安全课

本课程聚焦 Web 安全攻防与 SDL 实践，涵盖 SQL 注入、XSS、CSRF、文件上传等常见漏洞的攻击原理、应急响应与代码修复，并结合入侵案例、后门检测、提权防御及系统加固，强化安全开发与实战防护能力。

#### Agent16：APP 安全攻防与安全开发课

讲解 APP 安全合规，涵盖法律法规、监管态势及上架认证流程。通过分析典型违法违规案例，探讨 APP 开发中的安全风险与防范措施，包括数据保护、隐私合规及漏洞修复等。课程结合实际攻防场景，教授如何实施有效的安全策略和开发实践，确保 APP 从设计到上线的全生命周期安全合规。适合开发者、安全工程师及相关管理人员提升 APP 安全防护能力。

#### Agent17：API 安全攻防与安全开发课

本课程专注于 API 安全攻防与安全开发，涵盖常见 API 漏洞的实操与防范，包括过度的数据暴露、失效的对象级别授权、用户身份验证失效、资源缺乏和速率限制、功能级授权失效、批量分配漏洞、SSRF 及 NoSQL 注入等。通过实际案例分析与攻防演练，教授识别、利用及修复这些漏洞的方法，旨在提升学员在 API 设计、开发与安全防护方面的实战能力。

#### Agent18：云架构设计与安全设备实践课

本课程融合云架构设计与网络安全实践，涵盖防火墙、WAF、堡垒机、VPN 等安全设备部署，结合 Windows 与 Linux 系统攻防、应急响应及加固技术，通过云环境下的真实攻防场景，提升学员在混合架构中的安全防护与实战能力。

#### Agent19：K8S 漏洞巡检与安全编排保障实践课

本课程围绕 Kubernetes 漏洞巡检与安全编排，结合集群搭建、核心组件配置及常见攻击面（如 8080/6443/10250 端口、Dashboard 未授权访问等）实操演练，涵盖 Pod、Deployment、Service、存储等资源的安全使用与风险排查，并通过安全策略编排与应急响应实践，全面提升 K8S 环境的攻防对抗与安全保障能力。

#### Agent20：容器安全攻防与保障实践课

本课程聚焦容器安全攻防与保障实践，涵盖 Docker 基础、镜像投毒、Fork 炸弹、不安全挂载与配置导致的容器降级、逃逸等典型风险。通过真实场景演练，深入剖析攻击原理与防御策略，强化容器全生命周期的安全管控与应急响应能力。

#### Agent21：反电信网络诈骗法合规与防范实践课

本课程围绕《反电信网络诈骗法》核心要求，系统解读相关法律责任与合规要点，结合刷单返利、冒充公检法、虚假投资、钓鱼链接等典型诈骗手法剖析，讲解识别技巧与防御措施，提升个人与单位的法律意识、风险防范与应急处置能力。

#### Agent22：反诈效果提升实践与 AI 大数据智能分析课

本课程专注于提升反诈效果与应用 AI 大数据智能分析技术，结合《反电信网络诈骗法》的法律框架，深入剖析刷单返利、冒充公检法、虚假投资、钓鱼链接等常见网络诈骗手法及其防御策略。课程重点介绍如何利用 AI 和大数据进行智能风险识别、行为分析及实时预警，通过案例实操与模拟演练，增强学员运用先进技术手段预防和应对新型网络诈骗的能力，全面提升反诈工作的效率与精准度。适合安全管理人员、技术人员及相关从业人员学习，以强化反诈实战能力。

#### Agent23：网安法律合规与标准实践课

本课程系统讲解网络安全法、数据安全法、个人信息保护法等核心法律法规，结合等级保护 2.0、关键信息基础设施安全保护条例等标准要求，解析合规要点与实施路径。通过典型案例分析，涵盖数据分类分级、风险评估、安全管理制度建设等内容，帮助学员掌握网安合规框架下的实操方法，提升组织在法律遵从与安全治理方面的综合能力。

#### Agent24：数据安全合规与落地实践课

本课程专注于数据安全合规与实践，深入解读《数据安全法》及相关法规，涵盖数据分类分级、隐私保护、跨境传输等核心要求。通过实际案例分析，讲解数据生命周期各阶段的安全风险与应对策略，包括数据收集、存储、传输、使用、共享及销毁的合规管理。课程还将介绍如何利用技术手段（如加密、访问控制及审计机制）来保障数据安全，帮助学员掌握从政策制定到落地实施的全流程方法，确保组织在符合法律规范的同时提升数据安全防护能力。适合企业合规人员、安全管理人员及技术骨干学习。

### 智能体 1：Linux 操作系统安全攻防智能体

#### 对应课程内容

“Linux 操作系统黑客破坏场景重现与防范实践”，覆盖课件 1—系统隐患深度排查、2—安全溯源与痕迹提取、3—Linux 系统安全加固、4—溯源思维与应急响应闭环全部内容。

#### 核心教学任务

1. 掌握 Linux 系统隐患排查的核心命令与方法；
2. 完成入侵痕迹提取与溯源分析；
3. 实现 Linux 系统安全合规加固；
4. 建立应急响应闭环思维。

#### 配套故事线设计（企事业单位真实场景，多分支决策）

**故事背景：**某地级市政务服务中心官网后台 Linux 服务器被黑客入侵，篡改了首页公示内容，单位领导要求安全运维岗（学员扮演）2 小时内完成处置，避免造成舆情风险。

**可扮演角色：**政务中心安全运维专员、应急响应工程师。

**核心决策点与故事线分支：**

1. 决策 1：先排查系统隐患 → 进入“系统隐患排查”实操环节；完成后解锁“痕迹提取”分支，故事线推进为“发现黑客留有的后门账号，溯源到入侵 IP”。
2. 决策 2：先提取入侵痕迹 → 进入“安全溯源与痕迹提取”实操环节；完成后解锁“隐患排查”分支，故事线推进为“提取到黑客操作日志，定位到入侵漏洞为未修复的系统漏洞”。
3. 决策 3：先做系统加固 → 进入“Linux 系统安全加固”实操环节；完成后解锁“应急闭环”分支，故事线推进为“完成系统加固后，修复了所有高危漏洞，形成应急响应报告”。

**失败分支：**若实操任务未完成，故事线推进为“处置不及时，服务器二次被入侵，造成政务数据泄露，学员需重新完成实操任务”。

#### 智能体核心功能

1. **故事线引导模块：**场景动画、角色对话、决策点弹窗，每个决策点对应实操任务入口。
2. **实操命令模拟模块：**内置 Linux 命令行模拟环境，支持学员直接输入命令完成排查、溯源、加固操作，实时校验命令正确性。
3. **知识点讲解模块：**每个实操步骤配套课程知识点讲解，错误命令会弹出对应的知识点补全提示。
4. **闭环报告生成模块：**完成全流程实操后，自动生成应急响应报告，对应课程溯源思维与应急响应闭环要求。

### 智能体 4：电子商务系统入侵与防范智能体

#### 对应课程内容

“电子商务入侵分析与防范实践”，覆盖课件 04-1 蓝队 SQL 注入漏洞修复实践、04-2 蓝队跨站攻击漏洞修复实践、05-3 蓝队服务器巡检与加固实践、06 攻防对抗复盘与防御升级全部内容。

#### 核心教学任务

1. 掌握 SQL 注入、跨站攻击（XSS）漏洞的修复方法；
2. 掌握电商业务系统服务器巡检与加固方法；
3. 理解攻防对抗复盘的核心思路；
4. 掌握防御体系升级的核心方法。

#### 配套故事线设计（企事业单位真实场景，多分支决策）

**故事背景：**某国企旗下电商平台被黑客攻击，用户订单数据被篡改，平台暂停服务。学员扮演平台安全负责人，需在 24 小时内完成漏洞修复、系统加固、攻防复盘，恢复平台正常运行。

**可扮演角色：**电商平台安全负责人、蓝队防御工程师。

**核心决策点与故事线分支：**

1. 决策 1：先修复 SQL 注入漏洞 → 进入“SQL 注入漏洞修复实践”实操环节；完成后解锁“XSS 漏洞修复”分支，故事线推进为“修复了 SQL 注入漏洞，堵住了数据库篡改的入口，恢复了订单数据”。
2. 决策 2：先修复跨站攻击漏洞 → 进入“跨站攻击漏洞修复实践”实操环节；完成后解锁“服务器巡检”分支，故事线推进为“修复了 XSS 漏洞，避免了用户 Cookie 被窃取，完成了服务器安全巡检”。
3. 决策 3：先做服务器巡检加固 → 进入“服务器巡检与加固实践”实操环节；完成后解锁“攻防复盘”分支，故事线推进为“完成了服务器巡检与加固，修复了所有高危漏洞，完成了攻防对抗复盘报告”。

**失败分支：**若实操任务未完成，故事线推进为“漏洞修复不彻底，平台再次被攻击，造成用户资金损失，学员需重新完成实操任务”。

#### 智能体核心功能

1. **故事线引导模块：**国企电商平台场景、角色对话、决策点弹窗，每个决策点对应实操任务入口。
2. **漏洞修复模拟模块：**内置电商系统模拟环境，支持学员完成 SQL 注入/XSS 漏洞修复、代码审计、服务器巡检、加固配置等实操，实时校验操作正确性。
3. **复盘分析模块：**内置攻防对抗复盘框架，引导学员完成攻击路径还原、漏洞根源分析、防御优化方案制定。
4. **防御升级报告生成模块：**完成全流程实操后，自动生成电商系统防御升级报告，对应课程攻防复盘要求。

### 智能体 5：网站挂马与跨边界攻防智能体

#### 对应课程内容

“网站挂马入侵与防范实践”，覆盖课件 1.1—1.3 红队社工驱动的迂回渗透—网站挂马、2.1 蓝队跨边界攻击链还原、3—防御体系协同升级全部内容。

#### 核心教学任务

1. 掌握社工驱动的网站挂马渗透思路与方法；
2. 掌握网站批量挂马的实现原理与检测方法；
3. 掌握跨边界攻击链的还原分析方法；
4. 掌握防御体系协同升级的核心方法。

#### 配套故事线设计（企事业单位真实场景，多分支决策）

**故事背景：**某事业单位官方网站被批量挂马，访问网站的用户会被跳转至恶意页面，单位接到大量用户投诉。学员扮演单位安全应急响应专员，需在 12 小时内完成挂马清理、攻击链还原、防御升级。

**可扮演角色：**事业单位安全应急响应专员、红蓝队攻防工程师。

**核心决策点与故事线分支：**

1. 决策 1：先清理网站挂马 → 进入“网站挂马清理与检测”实操环节；完成后解锁“社工渗透路径还原”分支，故事线推进为“清理了所有挂马文件，溯源到入侵路径为社工攻击获取的后台账号”。
2. 决策 2：先还原跨边界攻击链 → 进入“跨边界攻击链还原”实操环节；完成后解锁“挂马清理”分支，故事线推进为“还原了黑客从社工攻击到挂马、到内网渗透的全攻击链，定位到漏洞根源”。
3. 决策 3：先做防御体系升级 → 进入“防御体系协同升级”实操环节；完成后解锁“攻击链还原”分支，故事线推进为“完成了防御体系升级，部署了网站防挂马系统，还原了攻击链，完成了漏洞修复”。

**失败分支：**若实操任务未完成，故事线推进为“挂马清理不彻底，网站再次被挂马，造成大量用户信息泄露，学员需重新完成实操任务”。

#### 智能体核心功能

1. **故事线引导模块：**事业单位官网场景、角色对话、决策点弹窗，每个决策点对应实操任务入口。
2. **挂马攻防模拟模块：**内置网站挂马模拟环境，支持学员完成社工渗透、挂马文件上传、批量挂马、挂马清理、攻击链还原等实操，实时校验操作正确性。
3. **攻击链可视化模块：**将跨边界攻击链以可视化流程图展示，引导学员完成每一步的还原分析。
4. **防御升级方案生成模块：**完成全流程实操后，自动生成网站防御体系升级方案，对应课程要求。

2. 决策 2：先构建内网代理隧道 → 进入“内网代理隧道构建”实操环节；完成后解锁“内网横向移动”分支，故事线推进为“构建了 socks5 代理隧道，进入目标内网，完成了内网资产探测”。

**失败分支：**若实操任务未完成，故事线推进为“内网渗透失败，无法定位核心资产防护漏洞，企业研发数据被黑客窃取，学员需重新完成实操任务”。

3. **攻击链构造模块：**引导学员完成多服务联动攻击链的构造，可视化展示攻击全流程。

### 智能体 7：网络安全攻击溯源分析智能体

#### 对应课程内容

“网络安全攻击溯源分析”，覆盖课件 1-1 数据流溯源、2-1 日志收集与分析、渗透痕迹分析全部内容。

#### 核心教学任务

1. 掌握网络层数据流溯源的核心方法；
2. 掌握安全日志的收集与分析方法；
3. 掌握渗透痕迹的提取与分析方法；
4. 掌握攻击溯源的全流程思路。

#### 配套故事线设计（企事业单位真实场景，多分支决策）

**故事背景：**某政务单位对外服务平台遭受网络攻击，服务中断 2 小时。学员扮演单位网络安全溯源分析师，需在规定时间内完成攻击溯源，定位攻击来源、攻击路径、攻击手法，形成溯源报告。

**可扮演角色：**政务单位网络安全溯源分析师、应急响应专员。

**核心决策点与故事线分支：**

1. 决策 1：先做数据流溯源 → 进入“网络层数据流溯源”实操环节；完成后解锁“日志分析”分支，故事线推进为“通过流量溯源定位到攻击 IP，追踪到攻击的网络路径”。
2. 决策 2：先做日志收集分析 → 进入“安全日志收集与分析”实操环节；完成后解锁“渗透痕迹分析”分支，故事线推进为“通过分析系统日志、Web 日志，定位到攻击的入口点”。
3. 决策 3：先做渗透痕迹分析 → 进入“渗透痕迹分析”实操环节；完成后解锁“全流程溯源报告”分支，故事线推进为“提取到黑客的操作痕迹、后门文件，还原了全攻击链，完成了溯源报告”。

**失败分支：**若实操任务未完成，故事线推进为“溯源失败，无法定位攻击来源，平台再次遭受同类型攻击，学员需重新完成实操任务”。

#### 智能体核心功能

1. **故事线引导模块：**政务单位网络中心场景、角色对话、决策点弹窗，每个决策点对应实操任务入口。
2. **溯源分析模拟模块：**内置流量日志、系统日志、Web 日志模拟环境，支持学员完成数据流溯源、日志查询、痕迹提取等实操，实时校验操作正确性。
3. **攻击链还原模块：**引导学员基于溯源结果，还原完整的攻击链，可视化展示攻击全流程。
4. **溯源报告生成模块：**完成全流程实操后，自动生成符合 CISAW 规范的网络安全攻击溯源报告，对应课程要求。

## 与当前项目方向的关系

- 当前方向“基于智能体的网络安全小助手开发”明确对应**附件一**与**第五部分设计实例**。
- 附件二服务于另一方向“基于大语言模型的 AI 安全工具开发实”，因此完成当前项目通常不需要依赖附件二。
- 实习考核要求最终提交四项成果：智能体规划设计方案、智能体功能手册、智能体源代码及数据库压缩包、智能体源代码安全审计报告。
