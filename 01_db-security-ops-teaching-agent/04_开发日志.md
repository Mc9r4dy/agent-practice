# 数据库安全运维教学智能体——开发日志

## 日志用途与记录规则

本文档用于按时间顺序记录“数据库安全运维教学智能体”的全部重要开发活动，包括需求确认、环境盘点、设计决策、文件变更、命令执行、测试验证、失败现象、根因分析、修复措施、回滚方式和后续计划。

记录规则如下：

1. 每条日志使用唯一编号 `DEV-YYYYMMDD-NNN`；
2. 所有修改文件、执行命令和测试结果均需记录；
3. 失败命令也必须记录，不只记录成功结果；
4. 密码、API 密钥、令牌、连接串中的秘密字段必须使用 `<redacted>` 表示；
   任何情况下均不得记录密码、完整令牌、API 密钥或其他可直接使用的秘密；
5. 日志只记录教学沙箱信息，不记录生产数据库数据或凭据；
6. 每条日志必须写明操作目的、实际结果、影响范围和下一步；
7. 已完成事项使用“完成”，未执行事项不得写成已完成；
8. 后续日志采用追加方式维护，不覆盖既有历史记录；
9. 大批量机械操作可以归并为一个动作，但必须列出涉及的文件和验证结果；
10. 所有涉及删除、重置、停止服务的操作必须额外记录目标校验和回滚方式。
